Atalhos do teclado

  • Alt + 'Z' :: quebra de linha (word wrap)
  • Ctrl + ',' :: abre configurações
  • Ctrl + '+' :: Zoon in
  • Ctrl + '+' :: zomm out
  • Alta + setas come/baixo :: move a linha ou seleção
  • Shift + mover cursor(setinhas/home/end/page down...):: vai selecionando
  • Alta + Shift + setas cima / baixo :: replicar linha/seleção
  • Ctrl + '' :: abre menu de sugestões
  • Ctrl + aspas :: mostra/esconde terminal
  • Ctrl + ; :: comentar/descomentar linha ou seleção
  • Ctrl + D :: selecionar próximas ocorrências
  • F2 :: remover variáver ou função
